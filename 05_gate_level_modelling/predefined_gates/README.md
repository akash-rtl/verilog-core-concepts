## Predefined Primitive Gates

Instantiation of Verilog predefined primitive gates for different input combinations.

### Gates Covered
- AND
- OR
- XOR
- NAND
- NOR
- XNOR


### Console Output:
``` 
   0 | i1 = 1, i2 = 0 | AND = 0  OR = 1  XOR = 1  NAND = 1  NOR = 0  XNOR = 0 
  10 | i1 = 1, i2 = 1 | AND = 1  OR = 1  XOR = 0  NAND = 0  NOR = 0  XNOR = 1 
  20 | i1 = 0, i2 = 0 | AND = 0  OR = 0  XOR = 0  NAND = 1  NOR = 1  XNOR = 1
```
